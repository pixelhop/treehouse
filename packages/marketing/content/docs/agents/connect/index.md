An agent can reach a workspace through a synced folder on your computer, through the Treehouse MCP server, or both. Over MCP, most agents sign in through your browser: you add the server URL, approve the agent and give it a name, with no key to copy. Agents that can't open a browser use an API key instead.

[How agents work with Treehouse](/docs/agents/connect/how-agents-work) explains the difference; the rest of this section is the set-up for each client, and how to manage the agents and keys you've connected. If you're an agent setting up someone's brand-new workspace, start with [set up a new workspace](/docs/agents/connect/set-up-a-workspace).
