A synced folder is the simplest way to work on a workspace from your own computer. It's an ordinary folder: edit files in any app, and anything on your machine that works with files, including coding agents like Claude Code, can use it too. Changes flow both ways within seconds.

On an Apple silicon Mac, the [desktop app](/docs/desktop/install-the-desktop-app) sets it up without a terminal. If you'd rather work from a terminal, use the [sync CLI](/docs/desktop/sync-with-the-cli). Both run the same sync engine underneath. Windows and Linux are coming soon; use the web app there for now.
