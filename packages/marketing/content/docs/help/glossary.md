| Term                           | Meaning                                                                                                                                                                                                                                            |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Activity**                   | The feed of every change in a workspace, marking which came from people and which from agents. See [activity](/docs/sharing/activity).                                                                                                             |
| **Agent**                      | An AI teammate that works in your workspace, through a synced folder or the MCP server. See [how agents work](/docs/agents/connect/how-agents-work).                                                                                               |
| **AGENTS.md**                  | A file at the workspace root holding the rules agents follow. See [write your AGENTS.md](/docs/playbooks/write-your-agents-md).                                                                                                                    |
| **API key**                    | A credential that lets an agent, script or the sync CLI act as you, for when signing in through a browser isn't possible. Labelled as agent or human, which decides how its changes are attributed. See [API keys](/docs/agents/connect/api-keys). |
| **Board**                      | A folder of markdown files shown as columns of cards, one column per `status:` value. See [boards](/docs/files/boards).                                                                                                                            |
| **Calendar view**              | A folder of markdown files with `date:` front matter, shown as a month calendar. See [folder pages](/docs/files/folder-pages).                                                                                                                     |
| **Comment thread**             | A review conversation attached to text in a markdown file. See [comments](/docs/sharing/comments).                                                                                                                                                 |
| **Conflicted copy**            | The second of two colliding edits, kept as its own file so nothing is lost. See [conflicted copies](/docs/files/conflicted-copies).                                                                                                                |
| **Connected agent**            | An agent that signed in to Treehouse through your browser and that you approved and named. It acts as you, as an agent, in every workspace you belong to. See [connected agents](/docs/agents/connect/connected-agents).                           |
| **Device**                     | A computer running the desktop app or sync CLI, approved in the browser for one workspace.                                                                                                                                                         |
| **Folder front page**          | A folder's `README.md`, `index.md` or `index.html`, shown when you open the folder.                                                                                                                                                                |
| **Front matter**               | YAML between `---` lines at the top of a markdown file, holding metadata such as `title` and `date`. See [front matter](/docs/files/front-matter).                                                                                                 |
| **Inbox**                      | A folder where anything can be dropped unsorted and filed later, usually by an agent. See [inbox and filing](/docs/playbooks/inbox-and-filing).                                                                                                    |
| **MCP server**                 | The Treehouse endpoint agents connect to, at `https://api.trytree.house/api/mcp`. See [MCP server](/docs/agents/reference/mcp-server).                                                                                                             |
| **Member**                     | A person who has joined a workspace. Members are Owners, Admins, Members or Viewers.                                                                                                                                                               |
| **Member link**                | A link to a file or folder that only works for members.                                                                                                                                                                                            |
| **Private**                    | A file or folder only the person who marked it, and their own keys, can see.                                                                                                                                                                       |
| **Public link**                | A read-only link to a file or folder that works for anyone who has it, optionally with a password. See [share links](/docs/sharing/share-links).                                                                                                   |
| **Restore to an earlier time** | Putting a folder or the whole workspace back the way it was at a chosen moment. See [restore to an earlier time](/docs/files/restore-to-an-earlier-time).                                                                                          |
| **Seedling, Grove, Forest**    | The Treehouse plans. See [plans and limits](/docs/account/plans-and-limits).                                                                                                                                                                       |
| **Synced folder**              | A folder on your computer kept in step with a workspace by the desktop app or CLI. See [how sync works](/docs/desktop/how-sync-works).                                                                                                             |
| **Trash**                      | Where deleted files wait, with the content they had, until someone brings them back. See [bring back deleted files](/docs/files/trash).                                                                                                            |
| **Version**                    | A saved state of a file. Every save adds one, and earlier versions can be restored. See [version history](/docs/files/version-history).                                                                                                            |
| **Viewer**                     | A member who can read and comment but can't change anything.                                                                                                                                                                                       |
| **Workspace**                  | A set of files and folders with its own members. Everything in Treehouse lives in one.                                                                                                                                                             |
