Treehouse is a shared file workspace for people and their agents. Everything in it is a plain file. You work in it through the web app or a folder on your computer that stays in sync; your agents work in the same files through that folder, the Treehouse MCP server or the REST API. Everyone sees the same files, every change is kept, and nobody's work is lost when two edits collide.

New here? Start with the [quickstart](/docs/get-started/quickstart). It takes about ten minutes and ends with an agent helping you set up your first workspace.

## For agents

If you are an agent, start with the [agent handbook](/docs/agents/handbook). It covers how to reach a workspace, the one rule that keeps everyone's work safe, and the conventions the web app understands.

Every page in these docs is also available as markdown: add `.md` to its URL, or use **Copy page** at the top of any page. [/llms.txt](/llms.txt) lists every page, and [/llms-docs.txt](/llms-docs.txt) has the whole manual in one file. The Treehouse [agent skill](/.well-known/agent-skills/treehouse/SKILL.md) packages the handbook for agents that support skills.
